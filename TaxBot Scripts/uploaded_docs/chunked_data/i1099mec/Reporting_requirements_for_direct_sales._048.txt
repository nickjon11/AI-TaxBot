Chunk Name: Reporting requirements for direct sales.
Summary: To report direct sales totaling $5,000 or more, use either box 2 on Form 1099NEC or box 7 on Form 1099MISC, and file with the IRS by January 31 if using Form 1099NEC. The recipient report does not need to be on the official form and can be a letter with the necessary information. Backup withholding applies if TINs are not provided, and state information boxes are optional for IRS reporting.

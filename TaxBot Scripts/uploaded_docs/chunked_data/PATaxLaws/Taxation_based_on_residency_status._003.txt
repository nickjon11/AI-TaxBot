Chunk Name: Taxation based on residency status.
Summary: The state of domicile taxes income earned by residents, while non-sourced income requires a resident credit from the state of statutory residence. Filing statuses include Single (unmarried or divorced), Married Filing Jointly (even if living apart), and Married Filing Separately (for spouses with different residency statuses). Surviving spouses can file jointly with deceased spouses, and specific residency conditions apply for tax credits.
